Super Commands.

Every Super key command in ASCS, including window tools and workspace actions.

Super

Super is the dedicated command key.Tap it to open the Command Center, or hold it while pressing a listed key.

01

ASCS views

Open a workspace inside ASCS

SuperCommand CenterOpens the main ASCS interface when Super is tapped by itself.ACTIVE
Super+SpaceCommand launcherSearch apps, ASCS views, and system actions.ACTIVE
Super+QQuick NotesOpens the persistent notes editor (default; configurable).ACTIVE
Super+ISystem DashboardShows live metrics and physical system details (default; configurable).ACTIVE
02

Applications

Launch a Windows application

Super+FEverythingOpens Everything, ready to search as you type (default; configurable).ACTIVE
Super+BVivaldiFocuses Vivaldi on this desktop, switches to its desktop if needed, or opens the browser.ACTIVE
Super+TWindows TerminalFocuses an existing window, switching desktops if needed; hold Shift for a new window (D/F create Explorer items).ACTIVE
Super+EFile ExplorerFocuses an existing window, switching desktops if needed; hold Shift for a new window (D/F create Explorer items).ACTIVE
Super+CCalculatorOpens Calculator (default; configurable).ACTIVE
Super+HTask ManagerOpens Task Manager (default; configurable).ACTIVE
03

Explorer items

Create items in the active File Explorer folder

Super+Shift+DNew folderPrompts for a folder name and creates it in the active Explorer location.ACTIVE
Super+Shift+FNew filePrompts for a filename including its extension and creates an empty file in the active Explorer location.ACTIVE
04

Virtual desktops

Switch to a numbered Windows virtual desktop

Super+1–9Desktop 1–9Focuses the numbered virtual desktop (top row or numpad).ACTIVE
Super+Shift+1–9Move active window to desktopMoves the focused resizable window and switches there; nonexistent desktops are ignored.ACTIVE
05

Window positioning

Arrange the active resizable window

Super+←/→Snap left / rightPlaces the active window in half of its monitor work area.ACTIVE
Super+↑/↓Maximize / restore / minimizeUp maximizes; down restores a maximized window or minimizes it.ACTIVE
Super+←, then ↑Snap to a quadrantPress a horizontal arrow, then an up/down arrow within 150 ms. Any direction pair selects its corresponding quadrant.ACTIVE
Super+Shift+←/→Move to adjacent monitorMoves the active window left/right; Preferences controls whether its size is preserved.ACTIVE
06

System controls

Control Windows features

Super+LLock workstationLocks the current Windows session.ACTIVE
Super+MToggle audio muteMutes or unmutes system audio.ACTIVE
Super+VClipboard HistoryOpens the Windows clipboard history with Win+V.ACTIVE
07

Text utilities

Type date and time at the cursor

Super+JInsert timestampTypes the current date and time: yyyy-MM-dd HH:mm:ss.ACTIVE
Super+YInsert dateTypes today's date: yyyy-MM-dd.ACTIVE
08

Workspace and capture

Save and restore your visible app layout

Super+SSave workspaceStores the visible app layout locally. Hold Shift with S for Snipping Tool.ACTIVE
Super+Shift+SSnipping ToolOpens the Windows screen-snipping overlay.ACTIVE
Super+RRestore workspaceRelaunches missing apps and restores saved window positions.ACTIVE

Default letter assignments for apps and views can be changed in Preferences. S, R, L, M, V, J, and Y are reserved for fixed commands. Super + Shift + D/F create Explorer items when File Explorer is active; unassigned Super + D passes through to Windows Show Desktop.
