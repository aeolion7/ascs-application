F24 Commands.

Every Super key command currently defined in ASCS, in one place.

F24

F24 is your Super key.Tap it to open the Command Center, or hold it while pressing a listed key.

01

ASCS views

Open a workspace inside ASCS

F24Command CenterOpens the main ASCS interface when F24 is tapped by itself.ACTIVE
F24+QQuick NotesOpens the persistent notes editor.ACTIVE
F24+ISystem DashboardOpens the system metrics view.ACTIVE
02

Applications

Launch a Windows application

F24+FEverythingOpens Everything, ready to search as you type.ACTIVE
F24+TWindows TerminalOpens Windows Terminal.ACTIVE
F24+EFile ExplorerOpens File Explorer.ACTIVE
F24+CCalculatorOpens Calculator.ACTIVE
F24+HTask ManagerOpens Task Manager.ACTIVE
03

Virtual desktops

Switch to a numbered Windows virtual desktop

F24+1–9Desktop 1–9Focuses the numbered virtual desktop (top row or numpad).ACTIVE
04

Window positioning

Arrange the active resizable window

F24+←/→Snap left / rightPlaces the active window in half of its monitor work area.ACTIVE
F24+↑Maximize windowMaximizes the active resizable window.ACTIVE
F24+↓Restore / minimizeRestores a maximized window; otherwise minimizes it.ACTIVE
05

System controls

Control Windows features

F24+LLock workstationLocks the current Windows session.ACTIVE
F24+MToggle audio muteMutes or unmutes system audio.ACTIVE
F24+VClipboard HistoryOpens the Windows clipboard history with Win+V.ACTIVE
06

Text utilities

Type date and time at the cursor

F24+JInsert timestampTypes the current date and time: yyyy-MM-dd HH:mm:ss.ACTIVE
F24+YInsert dateTypes today's date: yyyy-MM-dd.ACTIVE
07

Workspace and capture

Workspace controls are placeholders in the current backend

F24+SWorkspace save requestCurrently logs a request; workspace saving is not implemented.PLACEHOLDER
F24+Shift+SSnipping ToolOpens the Windows screen-snipping overlay.ACTIVE
F24+RWorkspace restore requestCurrently logs a request; workspace restoration is not implemented.PLACEHOLDER
