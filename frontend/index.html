            Default letter assignments for apps and views can be changed in Preferences, where you can also give custom commands their own letters. B, S, R, L, M, V, J, and Y are reserved for fixed commands. With Shift, C, P, D, and F always perform their Shift-layer action (capture, paste a note, new folder, new file). When C, D, F, or P has no assignment, Super + that letter passes through to Windows (for example, Win + D shows the desktop). Super + Shift + S saves the current layout under a name you type; the Snipping Tool is in the command palette. On their own, the macro keys (M1 to M7) and the Code key belong to the keyboard's macro scripts; with Super, M4 to M7 run the game commands above, and with Super + Shift they are deliberately vacant.
