Before you start
  1. Restart ASCS so 1.8.1 is running (tray › Exit, then the ASCS Launcher shortcut). The sidebar should read ASCS 1.8.1.
  2. Double-click C:\Scripts\Sync Startup Folder.cmd and accept: it copies the new Shutdown Sound.ahk into the Startup folder and restarts it. (SignIn.ahk is used where it is, so it's already live.)
  3. Backups from before 1.8.1: C:\Scripts\Backups (before ASCS 1.8.1) and C:\ASCS\data\backup-before-1.8.1-…. The old Aeolionware Startup folder is in the Recycle Bin.
